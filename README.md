## 代码在干什么（面试前必看）

### get_data.py —— 抓数据

| 代码 | 作用 |
|---|---|
| `requests.get(url, headers=HEADERS)` | 下载网页；`headers` 里放 User-Agent 假装浏览器，否则会被拒 |
| `BeautifulSoup(resp.text, "html.parser")` | 把 HTML 变成可以查找的结构 |
| `soup.select("div.item")` | 找到页面上所有电影条目 |
| `re.search(r"(\d+)人评价", ...)` | 用正则从"1234567人评价"里把数字抠出来 |
| `time.sleep(3)` | 每翻一页休息 3 秒，避免给对方服务器压力、也避免被限流 |

**分页原理**：豆瓣 Top250 一共 10 页，每页 25 部，靠 URL 里的 `start` 参数翻页（0、25、50……225）。

### analyze.py —— 清洗 + 统计

| 做了什么 | 为什么 |
|---|---|
| `pd.to_numeric(..., errors="coerce")` | 网页上抓下来的评分、人数、年份都是**文字**，要转成数字才能算平均、排序 |
| `drop_duplicates(subset=["片名"])` | 同一个榜单翻页可能有重复，要去掉 |
| `年份 // 10 * 10` + "s" | 把 1994 变成 "1990s"，年代分组 |
| 类型字段 `split()` 后逐条计数 | 一部电影有多个类型（"犯罪 剧情"），要拆开才能统计每个类型各有多少部 |

### plot.py —— 画图

- `matplotlib.use("Agg")`：不弹窗口，直接把图存成文件
- `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei"]`：让图里能显示中文，不加这行中文会变成方框

## 面试问答（重点准备这几条）

| 面试官问 | 你这样答 |
|---|---|
| 数据怎么来的？ | 用 requests 请求豆瓣 Top250 的 10 个分页，每页间隔 3 秒，共抓到 250 部电影的片名、评分、评价人数、年份、国家、类型 |
| 为什么要加 User-Agent？ | 默认的请求头会被网站识别成爬虫直接拒绝，加上浏览器 UA 才能正常返回 |
| 为什么要 sleep？ | 一是别给对方服务器造成压力，二是请求太密集容易被封 IP |
| 清洗做了什么？ | 评分/人数/年份从文字转成数字；片名去重；类型字段拆开；无效行丢掉 |
| 为什么类型要拆开？ | 一部电影有多个类型，不拆开只能统计"犯罪 剧情"这种组合，拆开才能知道单个类型各有多少部 |
| 有什么结论？ | 比如"1990s 和 2010s 的电影最多"、"美国片占比最高"、"剧情类占比最高" |
| 这个项目有什么不足？ | 只有 250 部，样本有偏（是用户评分选出来的）；网页结构变了爬虫就会失效，实际工作中要用 API 或更稳的解析方式 |

## 报告怎么写（1 页就够）

1. 数据来源：豆瓣电影 Top250，抓取日期 X 年 X 月 X 日
2. 数据量：250 条，7 个字段
3. 清洗口径：文字转数值、去重、类型拆分
4. 三条结论（从 analyze.py 的输出里挑）：
   - 年代分布：哪十年最多
   - 国家分布：哪个国家占比最高
   - 类型分布：哪些类型最常见
5. 局限：样本只有 250 部、结构变化会导致爬虫失效
